# CodexMeter Companion 3.12.3.5

Both the Waveshare C6 and Spotpear Ball V2 can now receive usage and chat updates over a USB data cable. A Windows PC can run either display without a Bluetooth adapter. In Auto mode the companion prefers a stable USB connection and falls back to Bluetooth LE when available. Each registered display has its own connection mode and settings.

The control panel now reports when an installed Codex version stops supplying a particular reading. Both displays distinguish an unknown task count from zero. The desktop token and cost report shows when its readings were collected, and settings controls report whether the display acknowledged a command.

Download **CodexMeter.exe** and the **factory image for your exact board**. Use the matching firmware to enable USB communication and partial task counts. See SETUP.md for flashing and SHA256SUMS.txt for file verification.

Known limitations include scanning a port already in use by the companion and registering the same board twice under different ID forms. Register each display once. Hardware sleep/resume and a sustained production run remain unverified for this release.
