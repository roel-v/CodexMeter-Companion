# CodexMeter Companion 3.12.3.9 for Windows

The display could show zero or one running chat while several were active in Codex Desktop. The companion now counts chats that Desktop assigns to sidebar sections, projects, or pins in its SQLite inventory as well as chats in its older sidebar lists. This fixes the undercount for both Running and Waiting.

To update, download **CodexMeter.exe**, quit CodexMeter from the system tray, replace the old executable, and start it again. Keep the same file path if you use a login shortcut.

The Waveshare C6 and Spotpear Ball continue to use firmware **3.12.3.8**. Updating the companion is sufficient for this fix. [Firmware for both displays](https://github.com/roel-v/CodexMeter-Companion/releases/tag/windows-c6-2026.11.25)
