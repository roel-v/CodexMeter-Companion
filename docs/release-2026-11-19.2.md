# CodexMeter Companion 3.12.3.7 for Windows

Open the control panel from the tray and select **Keep this PC awake while Codex turns are running**. You can change it while the bridge is running. CodexMeter remembers your choice at the next login and shows when it is holding a power request.

To stop this PC searching for a display you have moved elsewhere, open **Displays**, select the display and choose **Disable auto-connect**. Choose **Enable auto-connect** when you bring it back. Its registration is saved.

To update, download **CodexMeter.exe**, quit the companion from its tray menu, replace the old executable and start it again. Keep the same path if you use a login shortcut.

Both the C6 and Ball continue to use firmware **3.12.3.5**. [Firmware downloads and flashing instructions](https://github.com/roel-v/CodexMeter-Companion/releases/tag/windows-c6-2026.11.19)
