# CodexMeter Companion 3.12.3.6 for Windows

The companion now asks Windows to keep the PC awake while local Codex turns are running. When all turns finish or are waiting for input or approval, Windows can resume its normal idle sleep timer. The screen can turn off as usual.

The request survives brief gaps in telemetry and expires five minutes after the last confirmed running count. To opt out, launch the companion with `--daemon --no-prevent-sleep`.

Download **CodexMeter.exe**, quit the current companion from the tray, replace the executable and start it again. Keep its path if you use a startup shortcut.

Both the Waveshare C6 and Spotpear Ball V2 continue to use firmware **3.12.3.5**. Existing displays need no flashing. [Firmware downloads and setup instructions](https://github.com/roel-v/CodexMeter-Companion/releases/tag/windows-c6-2026.11.19).
