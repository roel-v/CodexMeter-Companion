# CodexMeter Companion 3.12.3.8

The companion keeps the last known weekly quota and reset time when the PC wakes or Codex is unavailable. Both displays mark that reading as stale and return to live figures when Codex responds.

On the Waveshare C6, swipe twice to the left from the Classic Tasks dashboard for a larger weekly percentage, the reset countdown, and Running, Waiting and Done. Swipe once more to return home.

On Windows, the companion installs its live chat-count helper by default. If Codex Desktop was already open, let your turns finish, then fully quit and reopen Desktop. You can turn the helper off in the companion control panel. An existing custom CLI path is preserved.

Download **CodexMeter.exe** for Windows and the **factory image for your board** to get the display changes. See **SETUP.md** for the flashing command and **SHA256SUMS.txt** to verify your downloads.
